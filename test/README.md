# Local test data

The original Docker package contained a local test MRI and generated outputs.
Those files are intentionally excluded from this public GitHub-ready package.

To run `./do_test_run.sh`, place a permitted ISLES'26-compatible local test case
under the expected `test/input/interf0/` structure.

Do not commit challenge MRI data, labels, or generated patient-specific outputs
unless the applicable data license explicitly permits redistribution.
